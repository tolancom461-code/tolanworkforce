# استثناء المجموعات من إلزام تعيين موقع التشغيل

## الهدف
إضافة خيار إداري على المجموعة باسم **مستثناة من إلزام تعيين موقع التشغيل**.

عند تفعيل الخيار:
- لا تظهر المجموعة في شبكة التوزيع السريع لموظفي التشغيل.
- عمالها لا يدخلون ضمن شرط وجود موقع تشغيل قبل إغلاق اليوم التشغيلي.
- إذا كانت المجموعات الوحيدة غير المسندة للمشرف هي مجموعات مستثناة، يستطيع المشرف إغلاق المركز؛ أما وجود مجموعة غير مستثناة خارج صلاحياته فيبقي الإغلاق ممنوعًا.
- الحضور والساعات والرواتب والاستدعاءات وبقية بيانات المجموعة لا تتغير.
- التغيير يُسجل ضمن سجل تدقيق تحديث المجموعة الحالي `UPDATE_GROUP`.

## قاعدة البيانات
نفّذ يدويًا:

```sql
ALTER TABLE `groups`
  ADD COLUMN `is_operational_assignment_exempt` tinyint NOT NULL DEFAULT 0
  AFTER `is_flexible_schedule`;
```

القيمة الافتراضية `0` تعني أن جميع المجموعات الحالية تستمر كما هي، ولا يتم استثناء أي مجموعة تلقائيًا.

## ملاحظات
الاستثناء يخص **إلزام التوزيع على موقع تشغيل فقط**، وليس استثناءً من الحضور أو الرواتب أو الاستدعاءات أو التقارير المالية.
