# تعليق شرط إغلاق اليوم التشغيلي قبل إنشاء مسودة الرواتب

تم تعليق الشرط افتراضيًا بدون حذف منطق التحقق.

## الوضع الحالي

إذا لم يتم تعريف المتغير التالي، أو كانت قيمته `false`، يمكن إنشاء مسودة الرواتب حتى مع وجود أيام تشغيلية غير مغلقة:

```env
REQUIRE_OPERATIONAL_DAY_CLOSED_FOR_PAYROLL_DRAFT=false
```

## إعادة تفعيل الشرط لاحقًا

أضف أو غيّر المتغير إلى:

```env
REQUIRE_OPERATIONAL_DAY_CLOSED_FOR_PAYROLL_DRAFT=true
```

ثم أعد تشغيل التطبيق.

لا يوجد أي Migration أو SQL لهذا التعديل، ولا تتغير بقية شروط إنشاء المسودة مثل منع التكرار والملاحظات التشغيلية والبصمات الناقصة.
